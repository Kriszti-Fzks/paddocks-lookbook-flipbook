# The Paddocks Lookbook

Interactive digital flipbook showcasing The Paddocks equestrian facility.

## Features

- 📖 Smooth page-flip animation
- 📱 Responsive design (works on mobile, tablet, desktop)
- ⌨️ Keyboard navigation (arrow keys)
- 🖱️ Mouse/touch support
- 📍 Page counter
- 📂 11-page lookbook

## View Online

Visit: [your-github-username.github.io/paddocks-lookbook-flipbook](https://your-github-username.github.io/paddocks-lookbook-flipbook)

## Local Development

1. Clone this repo
2. Open `index.html` in a browser
3. Use arrow keys or on-screen buttons to flip pages

## Files

- `index.html` - Main flipbook application
- `The_Paddocks_Lookbook_Page_*.jpg` - Lookbook pages (11 images)
